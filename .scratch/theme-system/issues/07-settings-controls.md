# 07: Settings, pickers, tooltips, and controls

**What to build:** Settings and shared controls use consistent semantic surfaces, text, borders, and interaction states in both Software Themes.

**Blocked by:** 01 Sidebar readability and Software Theme color roles.

**Status:** fixed

- [x] Settings navigation, cards, pickers, buttons, tooltips, and window controls have readable idle, hover, pressed, selected, focused, and disabled states where applicable.
- [x] Text and icons meet the spec's contrast targets on their actual surfaces, including translucent overlays.
- [x] Components obtain colors from Software Theme roles rather than local light/dark branches or unexplained literal colors.
