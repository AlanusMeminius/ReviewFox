# ReviewFox

Local clipboard-oriented code review over a Git two-tree comparison: browse structured diffs, attach draft comments, and export plain text for pasting elsewhere.

## Requirements

- macOS
- Rust (see `rust-toolchain.toml`)
- Git

## Build / install

```bash
./install.sh
```

Or build only:

```bash
cargo build --release
```
