# Dual-axis splitter: Beads shell, Zed row semantics

Pane resize uses a small dual-axis `splitter` (BeadsViewer `canvas` + `ResizeState` / `ResizeHandler`, session memory only, no double-click reset). Leading vertical rules resize from pointer `x`; trailing vertical rules from `viewport.width − x`; horizontal rules resize south-pane height via `cursor_row_resize` and `viewport.height − y` (Zed dock idea, window-local coords — never `window.bounds()`, which is screen-global). v1 wires the main-window splits: sidebar|stage, Commit float|Changes float, Changes file-tree|Head-meta, and optional MR detail|commit; Diff window wires tree|stage the same way.

Hit strips stay full-seam (full-height vertical / full-width horizontal). Default chrome is off (invisible strip). Opt-in chrome paints a short center stadium (3×24, always visible; hover/drag only change opacity, driven by hit-strip hover and `ResizeState.active` — not GPUI `group_active`). Rail seams (sidebar|stage, Diff tree|stage) fill the same frost gap as Commit|Changes (`CHANGES_SHADOW_GAP`); the island's own left inset applies only while that rail is collapsed. Dragging a rail below 160px snaps it shut and leaves the handle in the left gutter; dragging that handle 8px toward open restores the remembered width. MR detail|commit uses `CHANGES_INSET`; head-meta keeps 5px.
