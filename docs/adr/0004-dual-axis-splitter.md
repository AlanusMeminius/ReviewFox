# Dual-axis splitter: Beads shell, Zed row semantics

Pane resize uses a small dual-axis `splitter` (BeadsViewer `canvas` + `ResizeState` / `ResizeHandler`, session memory only, no double-click reset). Open/closed of the repo sidebar, the Diff file tree, and the comment island is not a splitter width (ADR-0012). Leading vertical rules resize from pointer `x`; trailing vertical rules from `viewport.width − x`; horizontal rules resize south-pane height via `cursor_row_resize` and `viewport.height − y` (Zed dock idea, window-local coords — never `window.bounds()`, which is screen-global). v1 wires the main-window splits: sidebar|stage, Commit float|Changes float, Changes file-tree|Head-meta, and optional MR detail|commit; Diff window wires tree|stage the same way.

Hit strips stay full-seam (full-height vertical / full-width horizontal). Default chrome is off (invisible strip). Opt-in chrome paints a short center stadium (3×24, always visible; hover/drag only change opacity, driven by hit-strip hover and `ResizeState.active` — not GPUI `group_active`). Rail seams (sidebar|stage, Diff tree|stage) use an 8px hit strip; Commit|Changes chrome fills the island frost gap (`CHANGES_SHADOW_GAP`); MR detail|commit uses `CHANGES_INSET`; head-meta keeps 5px.
