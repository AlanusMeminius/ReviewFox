# Block-first Replace; pairwise only when reliable

Dual-pane must show Alignment position relationships, not fake one-to-one line maps. A Replace is always a many-to-many Hunk (olds ↔ news); the center connector paints that block. Pairwise “old N → new M” and word-level highlight appear only when a refinement is reliable. Padding Replace into parallel DisplayRows that look 1:1 is rejected—it contradicts the domain and misleads reviewers (e.g. three old lines rewritten as one new line).
