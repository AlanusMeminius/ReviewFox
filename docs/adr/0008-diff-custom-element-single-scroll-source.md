# Dual-pane Diff is one custom Element with a single scroll source

The GPUI dual pane built a div per row for both panes and four line-number columns every frame, and drove vertical sync by letting native overflow scroll move, reading offsets back a frame later, and correcting them. That made per-frame cost proportional to file size and left a dead zone at the top where wheel travel moved nothing. We draw old pane, gutter and new pane as one custom GPUI `Element` that paints only visible rows from a pure Layout (per file, rebuilt on fold / ViewOptions change) and a pure Viewport (per frame), and we make `scroll_s`, clamped to the range where at least one side moves, the only vertical scroll source. `uniform_list` was rejected because its own scroll model fights the §3.1 piecewise gap; keeping divs with manual culling was rejected because it still rebuilds an element tree per frame. Behavior stays as specified in `docs/dual-pane-diff.md`; see `docs/diffview-architecture.md`. Extends ADR-0001.
