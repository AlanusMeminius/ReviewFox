# Syntax highlighting uses tree-sitter with a curated grammar set

Diff code needs syntax highlighting, and the languages actually reviewed are a small, fixed set. We use crates.io `tree-sitter` + per-language grammar crates, compiled in, and grow the set on demand; unlisted languages render as plain text. syntect was rejected despite its ~75 bundled syntaxes: regex/TextMate line-state highlighting has a lower accuracy ceiling, its scopes do not map directly onto the One Light capture roles we already use, and it leaves no path toward tree-aware features. Each Diff side is a read-only snapshot (ADR-0005), so we parse each side once and need none of Zed's incremental `SyntaxMap`; Zed's `language` / `languages` crates stay out (ADR-0001, and they are GPL), and their `.scm` queries are reference only, not copied. Cost accepted: a C compiler in the build and one dependency per language.
