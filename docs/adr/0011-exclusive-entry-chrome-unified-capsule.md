# Exclusive Entry chrome: kind track + value pill, last-MR memory

Branch Browser and MR selection must not co-appear as two parallel selection entry points: a Workspace selects exactly one Entry at a time. When GitLab chrome applies, titlebar Entry chrome is a **two-piece** control (visual source: `prototype/entry-kind-switch.html` variant **A**)—a capsule-track kind switch (`Branch | MR`) beside a separate value capsule (current branch name or `!IID` / `Select MR…`). Kind and value stay different affordances so switching Entry kind is not confused with opening the object picker. Default selected Entry on launch is Branch Browser. Switching to MR restores a Workspace-persisted last MR Entry label when present; otherwise opens the MR picker. Dismissing the picker with nothing selected leaves an empty MR kind (`Select MR…`); the value hit reopens the picker. While a picker is open, only the value capsule hides (anchor for the overlay); the kind track stays visible and clickable. Right-click on the value capsule while an MR Entry is selected clears that Entry (back to Branch Browser, last-MR memory kept). The last MR label may remain persisted while the selected Entry is Branch—it is memory for return, not a second selected Entry and does not drive Comparison until MR is selected again.

**Supersedes chrome shape in earlier ADR-0011 text** that chose a single unified hull (prototype A3). Behaviour (exclusive Entry, last-MR memory, empty MR + open-picker-on-enter) is unchanged; only chrome layout changed for affordance clarity.

**Considered options:** dual titlebar pills (both always visible); unified A3 single hull (kind + value shared); peer capsules for kind; morphing pill + kind menu; sidebar Entry sections; hiding both chrome pieces when a picker opens; forbidding empty MR kind. Rejected: dual pills co-advertise two Entries; A3 collapsed kind-switch vs value-pick into one control; peer/morphing/sidebar as before; hiding the kind track with the picker removes the switch while choosing; forbidding empty MR kind fought open-picker-on-enter.
