# Restore the selected Entry; persist shell open/closed globally

Opening a Workspace—process launch or choosing another one—restores that Workspace's selected Entry. An MR Entry label (`project` + `iid`) is activated on the existing MR path (refetch `diff_refs`). With no label, the selected Entry is Branch Browser. Empty MR kind (`Select MR…`) is not stored, so that open lands on Branch Browser while `last_mr` stays memory for a later kind switch (ADR-0011).

A failed refetch keeps that MR Entry, shows the failure on its detail, and leaves the label for the next open. It does not open the picker and does not select Branch Browser. When GitLab chrome cannot be shown, this open displays Branch Browser and does not clear the label; the next open restores the MR once chrome applies. Chrome becoming available mid-session does not switch Entry. The temporary Branch display is not written back as the selected Entry. An explicit Branch selection in that session (switch branch, or clear the MR Entry) still selects Branch Browser and clears the label, keeping `last_mr`. Restoring the main Entry does not change a persisted Diff Comparison (ADR-0005).

Shell open/closed is app-global, stored with window geometry, and written as soon as the preference changes: the main repo sidebar, the Diff file tree, and the comment island's toggle preference, including a drag that crosses its hide threshold. Widths stay session-only (ADR-0004). A narrow window yielding the comment island does not change the preference. Absent values default to sidebar open, Diff tree open, comment island closed.

**Considered options:** always open Branch Browser (the old ADR-0011 launch rule); treat a failed refetch like a kind-switch restore (empty MR and the picker); drop the MR label when chrome is hidden; persist open/closed per Workspace; persist splitter widths; write open/closed only on quit. Rejected: always-Branch discarded the place the user left; the picker and dropping the label turned a blip, a closed MR, or hidden chrome into a forgotten Entry; per-Workspace flags made a shell toggle look like repo state; widths stay session-only on purpose; a quit-only write loses the last toggle when the process dies.
