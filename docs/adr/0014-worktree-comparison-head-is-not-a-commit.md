# Worktree Comparison head is not a commit

A Worktree Entry reviews the checkout's on-disk tree against that checkout's HEAD. Its Comparison is `(repository, HEAD commit, Worktree)`: head is not a commit object ID (extends ADR-0002 for this Entry only). The label is `{HEAD short}..worktree`, in the title bar and the Export header. Every Review of uncommitted work against the same HEAD is one Review. An explicit refresh of the Entry re-reads the checkout for the main window; it does not mint a new Comparison and does not touch an open Diff. Anchors rebind when that Comparison is opened for review again; misses become UnresolvedAnchors (ADR-0005). Changing HEAD (commit, checkout, amend) is a new Comparison. The Worktree Entry then shows the new one and does not surface the previous Review; that Review remains stored and reappears if the checkout returns to the same HEAD commit. An open Diff stays the snapshot from when it was opened (ADR-0005), including when HEAD moves before the user refreshes. When the checkout matches HEAD, the path list is empty and Open Diff stays disabled even if that Review still holds comments. Those comments stay stored and rebind if the paths appear in a later open. There is no recovery surface for that empty list.

**Considered options:** a new snapshot id on every read (comments stick to a snapshot the Entry can no longer open); writing a temporary tree or commit into the repository object database (mutates the repo and pretends the user created a commit). Rejected.
